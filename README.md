## 🇪🇸 Español

**Classroom Assistant** es una aplicación web interactiva diseñada para facilitar la gestión diaria del aula a docentes. Incluye herramientas clave como un selector aleatorio de alumnos, un generador automático de grupos y un temporizador con alarma sonora.

### ✨ Características Principales

* 👥 **Gestión de Alumnos:** Guarda tu lista de clase directamente en el navegador. No perderás los datos al cerrar la pestaña.
* 🎲 **Selector Aleatorio:** Elige a un alumno al azar de forma dinámica y justa con animación.
* 🧩 **Generador de Grupos:** Organiza la clase en equipos equilibrados especificando cuántos alumnos quieres por grupo.
* ⏱️ **Temporizador con Alarma:** Mantiene el control del tiempo en las tareas de clase con alertas de sonido.
* 🌐 **Multilingüe y Accesible:** Soporte nativo para Español e Inglés con cambio de idioma instantáneo.
* 🌙 **Modo Oscuro/Claro:** Adaptable a la iluminación de cualquier aula o pizarra digital.

---

### 🚀 Cómo usarlo localmente

1. Clona este repositorio:
   ```bash
   git clone https://github.com/819774/classroom-assistant.git
   ```
2. Abre el archivo `index.html` en tu navegador favorito.
3. ¡Listo! No requiere servidor ni dependencias.

---

### 🛠️ Tecnologías Utilizadas

* **HTML5** & **JavaScript ES6+**
* **Tailwind CSS** (vía CDN)
* **Lucide Icons** (librería de iconos SVG)
* **Web Audio API** (para la generación del sonido de la alarma sin archivos de audio externos)
* **LocalStorage API** (para la persistencia local de datos de los alumnos en el navegador)

## 🇬🇧 English

> 💡 **Are you a teacher with no tech background?** Don't worry! This tool runs directly in your browser on any computer, tablet, or smartboard. No installation, sign-ups, or technical knowledge required. Just open it and start using it in your classroom! Here https://819774.github.io/classroom-random-picker/

**Classroom Assistant** is an interactive web app designed to streamline daily classroom management for teachers. It provides essential tools such as a random student picker, an automatic group generator, and a custom timer with a sound alert.

### ✨ Key Features

* 👥 **Student Roster Management:** Saves your class list directly in the browser so you never lose your data.
* 🎲 **Random Picker:** Pick a student fairly and dynamically with slot animation.
* 🧩 **Group Generator:** Instantly divide your class into balanced teams by specifying group sizes.
* ⏱️ **Classroom Timer:** Keep track of task durations with built-in audio alerts.
* 🌐 **Multilingual Support:** Instant switching between English and Spanish.
* 🌙 **Light / Dark Mode:** Tailored for any lighting condition or interactive whiteboard.

---

### 🚀 Local Usage

1. Clone this repository:
   ```bash
   git clone https://github.com/819774/classroom-assistant.git
   ```
2. Open `index.html` in your web browser.
3. That's it! No server setup or dependencies needed.

---

### 🛠️ Tech Stack

* **HTML5** & **JavaScript ES6+**
* **Tailwind CSS** (via CDN)
* **Lucide Icons** (SVG icons library)
* **Web Audio API** (for synthesizer audio alarm without external audio assets)
* **LocalStorage API** (for local student roster data persistence in browser)
